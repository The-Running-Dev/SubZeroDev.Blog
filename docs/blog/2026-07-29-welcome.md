The SubZeroDev Blog is now live.

<!-- truncate -->

This site is the public home for notes on building and maintaining SubZeroDev
projects. The first milestone is intentionally small: a documentation-backed
site, a repeatable publishing path, and a clear place for future posts.

Every post is written in this repository, reviewed through a pull request, and
published to GitHub Pages after merge. That keeps the published content tied to
the same source, checks, and history as the site that serves it.

For the current repository scope and local workflow, start with the
[documentation](https://blog.subzerodev.com/docs/). For the exact authoring
process, see [Writing Posts](https://blog.subzerodev.com/docs/writing-posts/).
