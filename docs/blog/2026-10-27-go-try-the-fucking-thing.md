# Go Try the Fucking Thing

For the last couple of days, I've been trying to use REA, Ghidra and these reverse-engineering tools to build free, open-source tools for myself. I'm curious how things work. I want to take things apart, understand them and see what I can reimplement. Meanwhile, people are losing their goddamn minds over how easy all of this supposedly is.

<!-- truncate -->

I've got twenty-five years of software experience. This still took me fucking hours to get to the point where I could do something I found useful.

Hours figuring out how to configure REA. How to set it up. How to give it access to Ghidra. How to access things, what it does and how it does it. Even for me, this is not a trivial thing.

Does it help? Absolutely. I'm using it because it helps. It makes it easier for someone like me to reverse engineer something, to copy an idea, clone functionality or reimplement a tool. I can see the usefulness while I'm working with it. I can also see how much fucking work is still involved.

Then I see the hype turned up a thousand degrees, and I'm sitting here laughing my ass off. People talking as though the existence of these tools means cloning software has suddenly become easy. Developers on YouTube freaking out about reverse engineering and legal issues, acting like fucking lawyers. That alone irritates the shit out of me.

I'm trying to configure the thing. They're having a whole goddamn crisis over what everyone can supposedly do with it.

What the fuck are we freaking out about? Based on what I've managed to do with it, I don't see the catastrophe people seem to be describing. I see something useful that still takes a hell of a lot of effort to use. Getting it configured well enough to produce something useful took hours. I still have to do the work of building the tools I actually want.

And some of this commentary is coming from experienced developers. That's what makes it so ridiculous to me. People who have spent years building software, who know how much work it takes to get something working, talking about these tools as if all that effort has just disappeared.

I want to tell them: shut the fuck up and go try the thing. Configure it. Use it. Try to clone whatever you think is now so fucking easy to clone. Then tell me how easy it was.

Because the hype and the misinformation make problems for people like me who are actually trying to use the tools. All this hysteria around something I'm sitting here trying to learn. I want to understand what it can do. I want to build something useful for myself. That's what I've spent the last couple of days doing.

I'm still curious. It still helps. And after twenty-five years of writing software, it still involves a shitload of fucking work.
