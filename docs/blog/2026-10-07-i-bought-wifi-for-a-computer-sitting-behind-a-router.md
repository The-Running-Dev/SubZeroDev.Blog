# I Bought Wi-Fi for a Computer Sitting Behind a Router

I bought a router yesterday.

Also a Wi-Fi adapter.

One of those USB things with a giant-ass antenna that looks like it is trying to contact a satellite.

The adapter was for the Mac mini behind the TV.

Perfectly reasonable.

Except directly behind the TV, approximately next to the computer I bought the adapter for, there is already another fucking router.

A 5G router.

I forgot it existed.

<!-- truncate -->

This requires clarification because otherwise somebody will think I accidentally built redundant internet.

No.

The redundant internet is deliberate.

Fiber comes in from outside.

Separate 5G connection exists as backup.

That part is architecture.

That part has a reason.

The accidental part is spending about seventeen euros on a Wi-Fi adapter because my brain temporarily deleted the networking equipment sitting behind the television.

## The Problem Was Memory, Not Networking

This is one of my favorite categories of technical problem.

The system works.

The design is fine.

The hardware already exists.

The failure is that the operator forgot his own infrastructure.

I was solving:

> How do I get the Mac mini onto wireless?

Meanwhile the answer was physically sitting behind the machine like:

> Hello, asshole.

Connect to me.

Problem solved.

## Deliberate Redundancy

The house has two independent ways to get online.

Fiber.

5G.

That is not overengineering.

That is me having spent enough years around networks to know that "the internet" is only one backhoe, provider outage, cable failure, power problem, or inexplicable Tuesday away from becoming "no internet."

So yes, I did that on purpose.

The adapter?

Not so much.

## Seventeen Euros

Fortunately this is not a major financial tragedy.

Seventeen euros.

Fine.

Now I own a spare Wi-Fi adapter with an antenna large enough to threaten nearby aircraft.

Eventually some machine will annoy me.

Some ancient box will need wireless.

Some Linux install will decide the onboard chipset is an ideological enemy.

Some random project will appear because I looked at a piece of hardware and thought:

> Well, why not?

The adapter will find employment.

Nothing in this house stays spare forever.

## Technomancer Inventory Management

I spend absurd amounts of time knowing how systems work.

Networks.

VPNs.

DNS.

Containers.

Operating systems.

Hardware.

Undocumented APIs.

Weird shit nobody should need to know.

Then occasionally the hardest technical problem is:

> Ben forgot there is a router behind the TV.

Excellent.

Twenty-five years of technical experience.

Redundant connectivity.

Multiple operating systems.

Home infrastructure.

And the root cause is inventory management.

I did not need a new networking solution.

I needed to remember the old networking solution was six inches away.

The 5G router has been restored to active memory.

The Mac mini has Wi-Fi.

The adapter is redundant.

The fiber remains deliberate.

The 5G remains deliberate.

Everything is fine.

Except apparently I need a CMDB for my living room.
